b43 firmware (ucode / PCM / initvals for Broadcom BCM43xx)

Source and how it was produced (reproducible):
  vendor : sources.openwrt.org/broadcom-wl-5.100.138.tar.bz2
           -> broadcom-wl-5.100.138/linux/wl_apsta.o
  cutter : github.com/mbuesch/b43-tools  (b43-fwcutter version 021)
  command: b43-fwcutter -w /tmp/fwout wl_apsta.o

Yields 117 .fw files (about 1.1 MiB) covering every PHY b43 supports:
  G-PHY   (802.11b/g: BCM4306 rev3 / BCM4311 / BCM4318 and friends)
  N-PHY / LP-PHY / HT-PHY / LCN / AC (newer cards)

BCM4318 (14e4:4318, e.g. BUFFALO WLI-CB-AMG54HP) needs these four:
  ucode5.fw  pcm5.fw  b0g0initvals5.fw  b0g0bsinitvals5.fw
(core rev 13 variants of the 4318 use ucode13 + b0g0initvals13 +
 b0g0bsinitvals13 instead)

Licence: these are Broadcom binary blobs (not the open-source b43-open ucode).
They ship with the image under this project's "closed-source firmware is
allowed" policy; the file contents are unmodified.
